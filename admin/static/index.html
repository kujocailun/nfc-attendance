QUICK START

使用指南

先连接，再读名单，最后同步签到记录。

第一次使用

  1. 给 SD 模块和主板供电，将主板 COM 口连接电脑。
  2. 进入“终端管理”，选择对应串口并连接。连接成功后会自动读取终端名单。
  3. 选择日期同步记录。连接期间，每隔约一分钟自动尝试同步终端当日记录；收到刷卡反馈后也会补齐当日文件。
  4. 在“人员与卡片”登记新卡。先刷卡获取 UID，再填写姓名并提交，终端确认后才显示已登记。
  5. 在“签到记录”按日期和姓名查询，点击导出保存 CSV。

离线使用与数据保存

签到终端始终以 SD 卡为记录来源。后台关闭或 USB 断开，不影响终端独立工作。下次连接后，按日期同步离线期间的文件。后台不会自动删除终端文件。

后台数据保存在 admin/data/attendance.sqlite3。可在“终端管理”下载一致性备份；还原时先关闭后台，再用备份替换数据库，并移走同名的 -wal、-shm 文件。

读懂统计

“当日已签到”表示本机收到的有效记录数。“当日未见签到”按当前终端名单比对，不能直接认定历史缺勤。一个人绑定多张卡时会分别计数。所选日期完整同步成功后，页面会显示同步时间。

暂时无法同步

提示没有有效文件时，可能当天尚无人签到，也可能文件存在异常，后台会保留本机已有数据。请查看 OLED、设备状态与日志。串口断开后，可刷新列表重新连接。校时使用电脑的北京时间，请先确认电脑时间正确。

运行范围

当前版本用于一台电脑管理一个终端，仅监听 127.0.0.1，支持 Windows 和主流桌面浏览器。没有云服务器、远程访问或多管理员账号。界面使用真实记录，初始数据库为空。
