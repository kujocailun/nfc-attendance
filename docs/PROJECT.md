# 课程项目简介

## 作品名称

基于 ESP32-S3 的离线 NFC 实验室签到与管理系统。

**本项目面向小型实验室管理员，解决现场网络不稳定时签到记录难以连续留存和集中汇总的问题。**

## 选题背景与目标

实验室签到包含现场登记和后续统计两个环节。如果记录过程依赖网络，手机热点关闭或无线连接中断就可能影响签到；记录分散保存在现场，又需要管理员事后整理。项目围绕“网络中断时仍能留下可汇总的有效签到记录”这一目标，设计能够独立工作的刷卡终端，并配套浏览器管理后台。

成员在终端刷卡后，应立即知道记录是否保存；管理员在网络恢复后，应能集中查看这些记录。离线保存、重复判断和联网补传共同服务于这一目标，屏幕、时钟和声光模块用于提供必要的时间依据与操作反馈。

## 简要功能说明

终端采用 ESP32-S3 主控和 PN532 读卡模块，读取实体 NFC 卡的 UID 并与人员名称绑定。DS3231 提供时间，microSD 保存名单和每日签到记录，OLED、LED 与蜂鸣器显示和提示操作结果。每张卡每天保存一条签到，同日重复刷卡提示“已签到”；数据写入后重新读取核对，通过后才提示成功。

终端可在断网状态下继续处理已登记卡的签到。连接 Wi-Fi 或安卓手机热点后，系统自动上传历史记录，并在后台去重。管理员通过 USB 本地后台或远程网页完成卡片登记、校时、名单读取和历史同步，也可查询每日统计、编辑人员备注、导出 CSV 与备份数据库。

例如，成员刷卡时手机热点关闭，终端仍按本地时间保存记录并反馈成功；热点恢复后，该记录出现在后台。成员当天再次刷同一卡片时，终端提示已签到，后台记录数保持不变。

## 项目范围与交付内容

项目定位为小型实验室签到原型，当前支持一台联网终端、一个管理员和至多 128 张登记卡，以北京时间自然日和卡片为统计单位。卡片 UID 不能防复制，系统不承担门禁认证，也不将“未见签到”直接认定为缺勤。

交付内容包括硬件原型、嵌入式固件、Web 管理后台、部署说明、自动测试和完整项目文档，并按立项、需求分析、系统设计、测试验收、成果汇报五个阶段组织。开发过程中使用 AI 辅助梳理需求、编写代码和文档，由开发者核对业务规则、完成接线与实物测试，并以编译、自动回归和现场操作结果检查生成内容。
