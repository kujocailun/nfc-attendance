# 项目简介

## 作品名称

基于 ESP32-S3 的 NFC 实验室签到终端与后台管理系统。

## 项目背景

实验室日常签到需要同时处理现场刷卡、记录保存和后续统计。网络不稳定时，依赖在线服务的终端容易中断使用；只在本地保存记录，又增加了汇总和维护工作。本项目将现场签到与后台统计分开处理，让终端在离线状态下仍可保存记录，并在恢复网络后同步。

## 简要功能说明

作品采用 ESP32-S3 作为主控，通过 PN532 读取实体 NFC 卡 UID，将卡片与人员绑定。终端使用 DS3231 提供实时时间，OLED 显示日期和签到结果，LED 与蜂鸣器提供操作反馈，microSD 保存人员名单和每日签到记录。

系统按“每张卡每天签到一次”的规则运行。重复刷卡提示已签到，不重复计数；记录写入后需要重新读取确认，失败时显示错误。终端支持 USB 本地管理，也可通过安卓手机热点连接远程后台。断网期间继续签到，恢复网络后补传历史记录。

后台提供每日统计、历史查询、人员备注、CSV 导出、数据库备份和设备管理。管理员可通过网页登记卡片、校时、读取终端名单、重扫历史，并查看任务执行结果。远程部署采用 Windows 常驻服务、Cloudflare Tunnel 和 Cloudflare Access，将管理页面与设备接口分开认证。

## 实现范围与成果

交付包括可工作的硬件终端、ESP32-S3 固件、浏览器后台、部署脚本、自动回归测试和项目文档。当前范围为一台联网终端，名单容量为 128 张卡。卡片 UID 用于课程签到演示，不承担防复制身份认证功能。

项目按立项、需求分析、系统设计、测试验收和成果汇报五阶段组织。提交文档使用通用项目描述，个人姓名、学号、专业和班级由提交者按学校要求另行填写。
