# 成果汇报提纲

## 作品与演示准备

作品名称为“基于 ESP32-S3 的 NFC 实验室签到终端与后台管理系统”。演示材料包括终端、两张测试卡、手机热点、管理浏览器和脱敏后的源码文档。测试卡使用演示名称，浏览器隐藏个人信息和生产配置，现场录像不展示热点密码或配对码。

## 建议演示顺序

先展示终端走秒和后台总览，再刷一张已登记测试卡，说明写入读回成功后才反馈。取走卡后再次刷卡，展示人数保持不变。

关闭热点，展示终端仍可进行本地判断。在后台发起远程任务，让页面保留“等待执行”。恢复热点后等待自动重连，展示任务最终回执与历史去重。最后展示按日期筛选和导出操作。

重启演示提前备份并按供电顺序操作；时间不足时可使用已脱敏录屏。不要在课堂演示中临时格式化 SD、擦除 NVS 或改生产 Access 策略。

## 讨论与后续工作

本版已实现现场采集、本地保存、远程管理和错误回执。主要工程问题是供电和接线稳定性、网络请求与本地刷卡解耦、离线补传幂等，以及界面异步刷新时保持可信状态。

后续可做单电源整合、固定外壳、多设备管理、中文显示和满容量压力测试。更强的身份认证需要重新选择卡片与密钥方案，不能通过扩展 UID 白名单获得防复制能力。
